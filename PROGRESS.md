## 0. Каркас — готово

- Astro 5.18.2, чистый CSS, без Tailwind. `npm install` прошёл, сборка чистая.
- Дизайн-токены (`src/styles/tokens.css`) — цвета и шрифты один в один из брифа.
- Пять грамматик движения (`src/styles/motion.css`) как CSS-переменные на `[data-branch]`:
  `--ease-micro / --ease-state / --ease-amb`, `--dur-micro / --dur-state / --dur-amb`, `--stagger`.
  Комнаты обязаны брать тайминги отсюда и нигде не писать `ease`/`linear` руками.
- `prefers-reduced-motion` решён глобально приёмом «paused + отрицательная задержка»:
  анимация замирает в середине своего цикла, а не обрывается в случайной точке.
- Тушевый переход между страницами (`src/styles/ink.css` + `src/scripts/ink-transition.js`):
  заливка из точки клика в цвет ветки назначения → навигация → расхождение пелены на новой
  странице. Флаг в `sessionStorage` + инлайн-скрипт в `<head>` поднимают пелену до первой
  отрисовки, поэтому приход в комнату не мигает голым фоном.
- Карта сайта вынесена в единый источник правды `src/data/rooms.js` — из него берут данные
  страницы, блок выходов, краулер и тесты.
- Главная страница собрана из утверждённого референса, пять кистевых меток ведут во входные
  комнаты веток, метка `心` — в колофон.
- Колофон `/colophon/` — тихая страница «что это», со списком всех комнат.
- Playwright (desktop / mobile / reduced-motion) + краулер связности + `npm run check-all`.

**Проверки:** сборка 22 страницы, краулер — битых ссылок, тупиков и сирот нет, все комнаты
в 1–2 переходах от центра. Playwright desktop — 5/5 зелёных.

## 1. Общая система — готово (частично, продолжается)

- `BrushMark.astro` — кистевые метки пяти веток как переиспользуемый компонент.
- `Room.astro` — оболочка комнаты: имя ветки на `<html>`, тихая шапка, выходы.
- `Exits.astro` — выходы: 2 соседа по ветке + всегда доступный путь к центру. Не меню.
- Библиотека приёмов `src/scripts/techniques/` — все 6 приёмов из брифа плюс модуль памяти
  между визитами. У каждого в шапке однострочный пример использования.

**Не сделано пока:** служебная страница-стенд для визуальной проверки грамматик движения.
